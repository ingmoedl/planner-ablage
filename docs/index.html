Aufgabe in Planner erstellen

Nur beim ersten Mal nötig — danach startet die Ablage künftig ohne Nachfrage.
Datei hierher ziehen oder auf den Punkt legen.
Die Datei wird im Jahres-Team des Projekts abgelegt und an die Aufgabe gehängt.
    Weitere Dateien einfach dazu ziehen.
    Alle Termine optional. Start und Fällig am zeigt Planner auf der Karte; das Ende steht in der Beschreibung.
